# Results

Comparison outputs will go here, for example:

- `wer_by_system.csv`: word error rate for each ASR system
- `impact_by_system.csv`: counts of None / Minimal / Significant errors per system
- `significant_errors.md`: examples of errors that changed clinical meaning
- Charts comparing systems and speakers

Raw, large, or temporary files go in `results/raw/`, which is not committed.
